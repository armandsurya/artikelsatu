# SEO Article Studio

CMS dan Website Jasa Pembuatan Artikel SEO berbahasa Indonesia yang dibangun menggunakan React, Vite, TypeScript, Tailwind CSS, dan Supabase.

## Tentang Project

SEO Article Studio adalah website company profile sekaligus Content Management System (CMS) yang dirancang khusus untuk layanan pembuatan artikel SEO.

Project ini terdiri dari dua bagian utama:

- Website Frontend
- CMS Admin

Frontend digunakan sebagai halaman pemasaran layanan, sedangkan CMS digunakan untuk mengelola seluruh konten website.

## Instalasi

Clone repository

```bash
git clone https://github.com/USERNAME/NAMA_REPOSITORY.git
```

Masuk ke folder project

```bash
cd NAMA_REPOSITORY
```

Install dependency

```bash
npm install
```

atau

```bash
bun install
```

Jalankan project

```bash
npm run dev
```

---

## Build Production

```bash
npm run build
```

Preview production

```bash
npm run preview
```

## Environment Variable

Buat file `.env` kemudian isi sesuai project Supabase.

Contoh:

```env
VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=
```
